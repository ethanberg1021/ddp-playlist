Free OBS plugin

DDP Playlist Player

Load your sponsors' commercials into a playlist, hit one button, and OBS cuts to the break, plays every spot in order, and cuts back to the show. Playlists save per project, and every control works from a Stream Deck through Companion.

Download for WindowsInstaller (.exe) · Windows 10/11 64-bit Download for MacInstaller (.pkg) · Apple Silicon & Intel

Requires OBS Studio 30 or newer · Version 1.0.0

Install

  1. Close OBS.
  2. Run the installer. Windows: if you see "Windows protected your PC", click More info → Run anyway. Mac: right-click the .pkg → Open.
  3. Open OBS. The DDP Playlist panel appears on the right (later: Docks → DDP Playlist).

Stream Deck / Companion

  • OBS connection → Custom - Send Vendor Request, vendor DDPPlaylist, request ToggleBreak.
  • Or Hotkey - Trigger by ID: ddp_playlist.take_break, ddp_playlist.play_pause, ddp_playlist.next…
